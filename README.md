# 💣 Bomb Clicker

**Bomb Clicker** — це проста гра на Python і Tkinter, у якій потрібно натискати на кнопку, щоб збільшувати Fuse і не дати бомбі вибухнути.

## 🎮 Як грати

1. Запусти програму.
2. Натисни **Enter**, щоб почати гру.
3. Натискай кнопку **CLICK THE BOMB!**
4. Кожне натискання додає Fuse.
5. Fuse поступово зменшується автоматично.
6. Якщо Fuse досягне `0`, бомба вибухне і гра закінчиться.
7. Натисни **RESTART**, щоб почати нову гру.

## ⭐ Особливості

* 💣 4 зображення бомби.
* 🔥 Fuse поступово зменшується.
* 🖱️ Клік по кнопці збільшує Fuse.
* 🏆 Є система очок.
* 💥 Є Game Over.
* 🔄 Є кнопка Restart.
* ⌨️ Гру можна запустити клавішею Enter.
* 🖼️ Зображення бомби змінюється залежно від рівня Fuse.
